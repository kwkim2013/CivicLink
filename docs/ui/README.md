# 공공민원 AI 업무지원 시스템 · MVP UI 10개 화면

로그인·회원가입·마이페이지 3개와 업무 메뉴 7개를 같은 스타일로 만든 정적 UI 목업입니다. 화면의 이름·기관·수치·문서는 예시이며, 실제 서비스를 구현한 결과가 아닙니다.

## 화면 구성

| 번호 | 화면 | 주요 기능 |
|---|---|---|
| 01 | [로그인](01-login.png) | 이메일·비밀번호 로그인, 이메일 저장, 회원가입 이동. |
| 02 | [회원가입](02-signup-v2.png) | 이메일 중복 확인, 비밀번호 확인, 소속 기관·부서 선택, 약관 동의. |
| 03 | [마이페이지](03-mypage.png) | 내 정보 수정, 비밀번호 변경 탭, 내 업무 현황, 로그인 기록. |
| 04 | [대시보드](04-dashboard.png) | 민원 접수·검토 현황과 자료 수집 현황을 함께 확인. |
| 05 | [민원 목록](05-complaints.png) | 검색·기간·분야·부서·상태 필터, 목록 조회, 페이지 이동. |
| 06 | [민원 등록](06-complaint-create.png) | 직접 입력·CSV 가져오기 탭, 파일 첨부, 등록 후 AI 분석 요청. |
| 07 | [AI 분석 결과](07-ai-review.png) | 민원 원문·요약·추천 이유·근거 문서·유사 민원 확인, 답변 초안 수정, 검토 완료. |
| 08 | [데이터 수집 관리](08-collection.png) | 수집처 관리·수집 실행 이력·수집자료 검토 탭, 원문 미리보기, 지식문서 등록. |
| 09 | [지식문서 관리](09-knowledge.png) | 문서 업로드, 등록 경로·검색 상태 필터, 문서 상세, 검색 제외·수정. |
| 10 | [처리 이력](10-history.png) | 처리자·작업·기간 검색, 변경 전후 비교, 처리 메모, 진행 이력. |

## 메뉴 구성

좌측 업무 메뉴는 대시보드, 민원 목록, 민원 등록, AI 분석 결과, 데이터 수집 관리, 지식문서 관리, 처리 이력의 7개입니다. 마이페이지와 로그아웃은 우측 상단 사용자 메뉴에서 엽니다.

## 구현 시 참고

- 민원 목록에서 선택한 민원을 AI 분석 결과 화면에서 검토합니다.
- 크롤링으로 수집한 FAQ·업무분장표·공개 사례는 참고 지식으로 관리합니다. 신규 접수 민원과 별도로 표시합니다.
- 수집 완료와 AI 검색 반영 완료는 별도 상태입니다. 수집자료 검토 후 지식문서로 등록합니다.
- AI 분류·추천 부서·답변 초안은 담당자가 수정하고 확정합니다.
- 탭으로 표시된 비밀번호 변경·CSV 가져오기·수집처 관리·실행 이력은 별도 이미지를 만들지 않았습니다. 이 패키지는 대표 화면 10개입니다.

## 생성 정보

내장 image_gen 도구를 사용했습니다. 공통 프롬프트와 화면별 최종 생성 지시는 prompts.json에, 회원가입 헤더 보정 지시는 signup-revision.json에 보관했습니다. 회원가입 최종 파일은 02-signup-v2.png입니다.
