# CivicLink React Frontend

## 실행

```powershell
cd C:\github\CivicLink\frontend
npm install
npm run dev
```

Vite가 출력하는 주소로 접속합니다. 기본 API 주소는 `http://localhost:8080`입니다. 다른 주소는 `.env`의 `VITE_API_BASE_URL`로 지정합니다. 로그인과 데이터 기능을 사용하려면 백엔드를 실행해야 합니다.

## 화면

- 로그인 / 회원가입: 비밀번호 표시, 비밀번호 확인, 중복 제출 방지
- 업무 대시보드: 실제 민원·결정례 수, 미분류 건수, 분야별 분포, 빠른 작업
- 민원 목록: 제목·번호·내용 검색, 분류 필터, 8건 단위 페이지 이동, 수정·삭제
- 민원 등록: 별도 입력 화면, 서버 규격에 맞춘 입력 길이 제한
- AI 분석: 분류·추천 이유·답변 초안·참고 결정례를 카드로 표시
- 결정례 검색: 검색 결과 선택 및 신청·결정 내용 상세 조회

참고 목업의 수집 관리, 처리 이력, 마이페이지는 이번 UI 변경 범위에 포함되지 않습니다. 실제 API가 지원하는 기능을 중심으로 구성했습니다. 회원가입도 현재 서버의 아이디/비밀번호 방식과 호환됩니다.

## 디자인

블루/화이트 톤, 접을 수 있는 사이드바, 공통 버튼·카드·표·입력 컴포넌트 스타일을 사용합니다. 태블릿에서는 콘텐츠가 한 열로 바뀌고, 모바일에서는 아이콘 메뉴와 가로 스크롤 표로 표시됩니다. 외부 폰트나 아이콘 CDN은 사용하지 않습니다.

## 검증

```powershell
npm run build
```

`work/ui-check/check.cjs`는 로컬 브라우저 UI 검증용이며, 가상 API 응답만 사용합니다. 실제 서버 연동 검증과는 별개입니다.
